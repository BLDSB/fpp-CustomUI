    Alerts

    Send an email alert if a scheduled playlist is not playing within the configured delay, or if the player stops responding altogether. Uses Gmail with an App Password (requires 2-Step Verification on your Google account). For SMS, enter your carrier's email-to-text address as the recipient (e.g. 5551234567@vtext.com for Verizon, @txt.att.net for AT&T). Fill in up to three recipients and every alert goes to all of them.

    Color Zones

    Rename zones or hide unused ones. These names appear on the Colors and Effects pages. All always covers the whole display — a site that needs only one zone can hide Zone 1–15 and use it alone. Zone names here are display-only — the Pixel Overlay Model names (All, Zone 1…Zone 15) must match what's configured on the controller.

    Import a layout from xLights to give each zone its real matrix shape, so overlay effects render across the model instead of along a single line.

    Network

    How this controller gets its address. A wrong value here can take it off the network entirely — if that happens, join the hotspot below, or plug a keyboard and screen into the controller and fix it from FPP's own menu.

    Reading the controller's network settings…
    Lowest number wins when two interfaces are up at once.

    Gateway and DNS belong to the whole controller, not just the selected interface. Leave them blank when DHCP supplies them.

    Save writes the settings and leaves the network alone — they come up at the next reboot. Save & Apply Now restarts the interface straight away, which drops this page if you are connected through it.

    WiFi Hotspot

    The controller's own access point, for reaching it when there is no usable network. Join it from a phone or laptop and this page answers at http://192.168.8.1/.

    Hotspot settings are read when the controller boots, so a change here takes effect after a reboot.

    Create Pixel Overlay Models

    This writes the pixel overlay models to the controller and restarts it. Zones with an imported layout get their full matrix shape and channel range. Zones without one keep the channel data already set on the controller — nothing you configured there is overwritten.

    A zone that has neither is created as an empty placeholder, and you must set its channel data on the Pixel Overlay Models page before it will work.

    Import Layout

    Reading the xLights display map on this controller. With more than 15 models, models are grouped into zones — by name where they share one, otherwise by channel order — so a single zone can drive several models. Check the shapes and change any zone below before importing.

    This show mixes 3-channel (RGB) and 4-channel (RGBW) models, so a single whole-display "All" model can't address them correctly. "All" will drive every zone instead.
